# Мессенджер - Обновленная версия

## Новый дизайн и структура

### Что изменилось:

#### 🎨 Дизайн
- **Современный градиентный интерфейс** с использованием фиолетово-синей цветовой схемы
- **Полностью адаптивный дизайн** для всех устройств (desktop, tablet, mobile)
- **Плавные анимации** и переходы для улучшения UX
- **Улучшенная типографика** с современными шрифтами
- **Кастомные скроллбары** в стиле приложения
- **Система уведомлений** с всплывающими сообщениями

#### 📁 Структура кода
JavaScript код теперь разбит на модули:

```
frontend/
├── index.html          # Главная страница
├── styles.css          # Стили (CSS переменные, адаптивность)
└── js/
    ├── config.js       # Конфигурация и глобальное состояние
    ├── api.js          # API запросы к backend
    ├── websocket.js    # WebSocket соединение
    ├── ui.js           # UI функции и взаимодействие с DOM
    └── app.js          # Основная логика приложения
```

### Основные возможности:

#### Адаптивность
- **Desktop (> 1024px)**: Полный интерфейс с боковой панелью
- **Tablet (768px - 1024px)**: Сжатая боковая панель
- **Mobile (< 768px)**: Выдвижное меню с гамбургер-кнопкой

#### UI/UX улучшения
- Автоматическая прокрутка к новым сообщениям
- Визуальная индикация активного чата
- Форматирование времени сообщений (сегодня, вчера, дата)
- Различие между своими и чужими сообщениями
- Модальное окно для управления участниками
- Система уведомлений для важных событий

#### Технические улучшения
- Модульная архитектура кода
- Переиспользуемые компоненты
- Централизованное управление состоянием
- Обработка ошибок с понятными сообщениями
- Автоматическое переподключение WebSocket
- Кэширование DOM элементов для производительности

### Запуск приложения:

```bash
# Запуск через Docker
docker-compose up --build

# Приложение будет доступно по адресу:
http://localhost
```

### Цветовая схема:

```css
--primary-color: #667eea      /* Основной фиолетово-синий */
--primary-dark: #5a67d8       /* Темный фиолетово-синий */
--secondary-color: #764ba2    /* Вторичный фиолетовый */
--success-color: #48bb78      /* Зеленый для успеха */
--danger-color: #f56565       /* Красный для ошибок */
```
